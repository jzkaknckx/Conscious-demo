# 视觉大模型认知算法架构：眼跳驱动与图记忆更新

> **【算法版图全维合并宣告与重心转移】**
> 以下文档中探讨重构的包括 `REVIEW`、`LEARN_MACRO`、`LEARN_MICRO` 三态引擎驱动机制、全新的 `tick_update` 延宕挂载时序设计，以及自适应面积步长等计算模型，**如今已作为最新全局规范并入至 `Algorithm_gmp.md` 主文档中**。
> 即日起，由 `Algorithm_gmp.md` （特别是其中的 _4. Controller 双极流状态机伺服循环_ 章节落定的新规则）掌管本项目双轨流视知觉引擎系统的全局权威。

## 一、 状态机三种状态定义与行为

### 1. REVIEW 状态（记忆验证阶段）
*   **行为目标**：对已有记忆特征（`interest_map`）高响应区域进行复查。
*   **计算模型**：注视点 $p_{next}$ 取决于记忆兴趣值与空间抑制的结合。
    $$p_{next} = \arg\max \left[ I_{map}(\mathbf{q}) - \alpha \cdot IoR(\mathbf{q}) - \gamma \cdot Dist(\mathbf{p}_{curr}, \mathbf{q}) \right]$$
*   **IoR 演化**：全局抑制图 $IoR(\mathbf{q})$ 每次注视后在当前点 $\mathbf{p}_{curr}$ 进行高斯叠加并自然衰减，强制打破多次定焦死锁。
*   **多通道特征投影响应的锐化匹配**：基于记忆向场景验证时，采用强分辨特异性的高阶投影矩阵提取特征。在通道余弦相似度夹角上施加非线性高阶幂（$k$），以此压制错误的多频杂波边缘，获取极其干净的特征响应结果。
    $$S_m(\mathbf{q}) = \left( \max \left( 0, \frac{X_m(\mathbf{q}) \cdot w_m}{||X_m(\mathbf{q})|| \cdot ||w_m|| + \epsilon} \right) \right)^k$$

### 2. LEARN_MACRO 状态（宏观寻找与漫游阶段）
*   **行为目标**：在退出微观扫描后，就近寻找新的、与刚刚所见特征不同（避免陷入局部循环）的显著特征点，准备触发下一轮微观追踪。
*   **宏观寻点与绝对防撞计算模型**：
    利用最新高阶图（GposII）及历史语义的响应组合构建掩码约束，杜绝重返复建认知废墟。
    $$M_{suppress} = \max \left( \operatorname{Norm}(M_{GposII}) , c \cdot \operatorname{Norm} \left( \textstyle\sum M_{semantic\_history} \right) \right)$$
    依据就近原则的平移选点方案：
    $$p_{next} = \arg\max \left( \left( I_{map} \odot (1 - M_{suppress}) \right) * K_{lowpass} - \gamma \cdot Dist(\mathbf{p}_{curr}, \mathbf{q}) \right)$$
*   **宏观空间实体建构 (GmemIII/EntityNode 组网)**：
    每一次 `LEARN_MICRO` 微观终结并发生大跨度跳跃转到新一轮物体端点前，所跨越的宏观眼跳向量 $\Delta\mathbf{p}$，会被作为空间位姿关系有向边，连接到更高维的 **GmemIII** 模型中。这实现了“局部组件到宏观房屋”的认知拼装。
*   **GposIII 宏观实体格式塔式检出**：
    利用 GmemIII 中的 $(\Delta\rho, \Delta\theta)$ 位量边叠加与平滑中心聚类操作（如：$D_{sum}^{III}(\mathbf{q}) = \sum \mathcal{G}_{\text{blur}}(M_{GposII}(\mathbf{q} - \Delta\mathbf{p}))$），在相关局部组件集体点亮时涌现出一个总体的宏观概念峰值，支撑格式塔跨度识别。

### 3. LEARN_MICRO 状态（微观连续特征追踪扫描阶段）
*   **行为目标**：摒弃孤立色块限制。目前对任何边、形、面等能生成 GposI 特征内导通连通域的连续特征，予以多次精细眼跳追踪。并整体打包入所属 **GmemII (局部组件层 / SemanticNode)** 节点。
*   **延迟隔离暂存 (Peripheral Buffer)**：所有视框扫过的边缘或色块采样进入临时队列中，防止中途退却破坏已有长效拓扑结构。
*   **动态能量扩散与约束掩码 (Dynamic Energy Diffusion)**：
    摒弃初版简单的静态距离衰减模型。改为在物理响应中维护一个不断萎缩的矩阵 $E_{dynamic}$：
    1.  **火种播撒**：在焦点激活 $V_0(\mathbf{p}_{init}) = 1.0$。
    2.  **导通拓扑域演化**：以 $M_{GposI}$ 回响图为通透系数介质，实施张量扩张 $V_{t+1} = \text{MaxPool2d}(V_t) \odot M_{GposI}$。其中配备**自适应终止优化 (Dynamic Early Stopping)**：监听空间积分面积变化率 $\Delta \rho$，当 $\Delta \rho < 10^{-3}$ 即蔓延停滞时截断循环，节省算力并保障结构贴合度。
    3.  **最终成型矩阵**：$E_{dynamic}(\mathbf{q}) = V_T(\mathbf{q})$。
*   **微观眼跳足迹消耗模型**：
    依据落子最大值生成眼跳：$p_{next} = \arg\max E_{dynamic}(\mathbf{q})$。单步抵达后，立即以高斯核啃食其附近能量（$E_{dynamic} \leftarrow \max(0, E_{dynamic} - \text{足迹})$）。
*   **动态分辨率与细节挖掘**：
    在微观流中一旦多次捕捉到超高相似度且开始原地打转复复探测时，自适应调低 `similarity_threshold`，使得系统对特征更敏感，强行刺破表面大色块伪装，进行次级纹理精细切割。
*   **二维面边界与一维轮廓线的协同交互学习算法**：
    1.  **面相先验寻边（入栈挂起）**：二维海洋中探索骤遇全新的高频狭长边缘线时，将二维面节点挂起入栈，就地触发子级 `LEARN_MICRO` 去专注首尾顺延该条边。
    2.  **线缝合填补（出栈协同）**：一维子边缘探索枯竭触发栈 Pop 时，新的一维 GmemII 节点直接贴靠给重新出栈继续寻找的海面。且针对 Gpos 记录的已知轮廓边界会直接建立拓扑关联捷径完成降维边界缠绕。
*   **跨距与时长积分的固有模态法 (Intrinsic Modality)**：
    不存储死板几何尺寸。改为记录 $T_{stay} = \sum 1$（探索用时计步）与 $S_{span} = \max ||\mathbf{p}_i - \mathbf{p}_{init}||$（极值跨长）。最终将这两项打包为定性标度（如“又长又大”原型）挂载于该 **GmemII** 特征关联字典中，作为其内生的感性尺度。

## 二、 三种状态流转条件

### 1. REVIEW / 初始 $\to$ LEARN_MACRO
*   **流转条件**：当记忆巡视失去特定关注目标，或者场景中高显著未标识度重新溢出，通过全局控制指令触发探索大循环，跃迁至 `LEARN_MACRO`。

### 2. LEARN_MACRO $\to$ LEARN_MICRO
*   **流转条件**：漫游寻找到未知的高显著极值落点，且未被目前涵盖全局建档防撞的历史 / 语义掩码覆盖时。该点激发的事件自动升级为全新的基础特征锚点确立事件，立即转入微观连续挖掘态的 `LEARN_MICRO`。

### 3. LEARN_MICRO $\to$ LEARN_MACRO
*   **流转条件（能量枯竭与模态突变退出）**：
    1.  常规耗尽：每次眼跳不断蚕食微观约束图，导致当前局部的 $E_{dynamic}$ 矩阵归零，即所处连通域边界内的可用势能已穷尽。
    2.  模态突变：探测中如视线逼近强边界导致强响应，诱发下一步注视点发生模态类型反转（例如从面状平坦区突然跃迁至高频边缘区）。即数学上相邻两步提取特征模态不一致时（$\text{Modality}(\mathbf{q}_{t+1}) \neq \text{Modality}(\mathbf{q}_t)$），强制触发流转退出。
*   **流转伴随动作（中心爆发群组建网与节点挂起/恢复）**：
    在退出并转场的瞬间触发：
    1.  **同源模态过滤与批量处理 (Batch Processing)**：GmemII 节点具备严格的模态从属性，仅当前 `peripheral_buffer` 内与中心锚点节点模态信息相符的 GmemI 节点，才被允许批量推入并挂靠成为该 GmemII 节点的子网络。
    2.  **未完成节点的挂起栈压入 (Suspend)**：系统为每个 GmemII 节点引入了 `is_completed` (布尔完成标记) 属性。若当前退出是由结构边界导致的模态突变（尚未全部探索完毕），系统会将该未完成的 GmemII 节点打上标记并压入栈中挂起，随后转去对新出现的周边异质特征群（如刚触碰的边缘）进行新一轮学习探究。
    3.  **栈追踪与闭合回收 (Resume & Complete)**：当周边扰动特征群被学习闭环后，系统会优先出栈并重回该未完成的二维 GmemII 节点，继续深耕其残余拓展区哪怕发生多次跳出复入，直到该区域探索彻底枯竭，最终将其 `is_completed` 置为 true，正式终结此节点的微观生命周期并更新宏观连通。

## 三、 节点能量更新时机

在此算法架构下，图动力学演化严格划分为 **节点内源电位常驻时序引擎计算** 与 **网格拓扑更新操作** 两个相互独立的象限。为了保证代码架构解耦与物理意义上的准确，旧有混杂的单点电荷结算升级为统筹式的独立节点更新范式。

### 1. 独立方法分封单步更新 (Independent Node Update Methods)
*   **机制分装**：将系统所有图结构节点的“能量电位更新”与“历时状态更新”（即 CALM $\to$ SPKE $\to$ ACTIVE $\to$ REFRACTORY 等流转法则）进行脱钩与封装，归纳为独立的方法接口。
*   **单步尾随驱动**：在控制中心每一次执行 `run_step()` 结束帧，不论当前状态机正身处 `REVIEW`、`LEARN_MACRO` 或 `LEARN_MICRO` 哪一阶段，都将**统一进行一次全局属性调用**。传入需要受到时间轴推移影响或新受激充能的活跃节点集合，集中履行其自身的算力折损与能量结算算法。
*   **Gpos 响应联动同步**：在执行完节点的能量和状态更新后，配套执行对活跃状态的节点在 Gpos 中的空间响应谱系实时推演。这保证了下一帧的探索完全基于正确流变的物理力场。在此独立更新方法中，依据所处的宏观/微观状态灵活加载特异化参数，保持高度的场景兼容。

### 2. 语义层级（GmemII）跨层捕获与向上传发激化
由于前代架构忽视高级聚合网络自身的激活充能，导致宏观防撞掩码模型形同废纸，引发局部死锁，在此解耦的单步尾随结算中，特设向上传递机制闭环：
*   **操作时机 (MICRO 定向泵注)**：处于 `LEARN_MICRO` 时，每挖掘并挂载一个具有符合模态条件的子块环节后，除了点亮子要素的 GmemI 层外，必须利用独立更新向父级成型的语义中枢节点逆向输送受刺激能量参数 `E_input_gmem_ii_acc[active_semantic_id] += E_stimulus`，实现跨层直接激活。
*   **操作时机 (跨越连带激发)**：常规扫视时若恰切触碰高等级位元空间重合区，依然纳入独立结算列表内给予重算联觉能量的额外刺激。
*   **物理效果**：因独立结算机制保证了每一个时钟跳动下上代锚点电势均稳步攀登甚至红温顶格，一旦视野切换回宏观态（`LEARN_MACRO`），藉由该锚点散发的防撞辐射场 $M_{GposII}$ 或历史记录即可对眼跳重返造成绝对拒止，实现了探险规避往复的历史突破。
