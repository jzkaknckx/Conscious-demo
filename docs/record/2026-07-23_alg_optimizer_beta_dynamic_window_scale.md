# 2026-07-23 Alg_optimizer_beta 动态视窗口尺度机制

- 更新 `docs/algorithm/Alg_optimizer_beta.md`，新增“动态视窗口与尺度选择”章节。
- 将视窗口半径定义为内生变量 $r_t\in[r_{min},r_{max}]$，并用固定总注意力预算推导窗口越大、最低写入特征尺度越大的约束。
- 补充候选尺度竞争函数，综合 Gpos 响应尺度、细节残差、粗结构连贯度、frontier 触边、多对象混合和有效视野质量选择窗口半径。
- 约束视窗口写入流程：大窗口只写入粗尺度结构，细节进入纹理统计与 `detail_pressure`；小窗口才允许细节成为独立 GmemI/GmemII 结构。
- 更新简化算法流程与风险控制，加入尺度化眼动步长、尺度分层访问抑制、尺度震荡与细节遗忘控制。
