## 2. aps 全图 NaN 的根因与传播链

代码：`src/nns/cnns/features.py` 的 `aspect_from_prepooled_J`，约第 91 行。

尺度 1 使用未空间平均的结构张量：`Jxx=dx², Jyy=dy², Jxy=dx*dy`。理论上这个矩阵半正定且秩不超过 1，较小特征值 lambda2 应为零；代码用 `0.5*trace - sqrt(disc)` 计算，在 float32 中会发生相消误差。

实测 2,430 个像素的 lambda2 小于零，最小值约 `-9.54e-7`。当前 `_EPS=1e-12`，远小于该误差，因此 `sqrt((lambda1+EPS)/(lambda2+EPS))` 可能对负数开平方，产生局部 NaN。随后 `val.abs().max()` 使用整图归一化：只要出现一个 NaN，最大值就成为 NaN，最终该尺度全部 65,536 个像素变成 NaN。尺度 2/4 经过结构张量空间平均，此图上没有复现 NaN，但当前公式本身仍没有保证非负特征值。

下游 `FeatureSupportBuilder.build` 先执行 `isfinite(original).all(dim=1)`。每个像素只要一个尺度无效，该像素就不可写；因此 aps 即使另两个尺度正常，全部位置也会被排除。随后用于质量计算的值经过 `nan_to_num`，故“Reliability”图仍可能有正常颜色，但 Writable gate、Support 与 Regions 全空。

这也说明上一轮五模态合成输入的写入测试只验证了接口，未覆盖真实 CNN 的特征生成。它不能证明此图片上 aps 正常；本次补充了真实 CNN 复现证据。

优先修复方向：在特征值/比值阶段处理半正定约束，使用与 dtype、结构张量量级相容的稳定分母，并明确零能量区域的输出；整图归一化必须避免单个异常污染全图。不能只把最终 NaN 替换成零当作修复，否则丢失一个尺度的信息而隐藏根因。是否允许部分尺度缺失需要另行定义通道 mask 合同，不应直接将 `all` 改为 `any`。

## 3. curv：有限值不代表正确的曲线结构

此图片 curv 没有 NaN/Inf，但支持像素中 11,599/13,588 被标为方向不可靠事件，约 85.4%。初始种子为 0，并非完全未构图：`RegionAssembler` 会为保留区域补选质量较高的点，最终仍有 51 个区域。

当前 curv 是 Hessian 分量平方和的归一化强度；其轨迹切向并非直接由 CNN 输出，而由局部支持强度的空间二阶矩估计。该估计的质量与方向一致性决定是否连接为 Trace_1D。将局部强度分布的主轴当作连续曲线方向，不一定适用于大面积或复杂纹理响应。种子又要求质量达到 .6 并满足邻域极大值；方向不可靠点成为事件，不能期待它们自然组成长曲线。邻域极大值当前在完整 quality 图上计算，邻域内不可写位置也可能影响种子选择，需另做掩码内/外对照。

额外零输入测试发现：`curvature_from_prepooled` 在平方根内加 `1e-8`，使零导数也得到 `1e-4`；再按该图最大值归一化，导致**全零图片的 curv 输出全为 1**。这是有限但错误的背景激活，需要处理无结构能量时的归一化，降低门槛不能解决它。

## 4. ori：弱结构置信度与方向几何存在问题

此图片 ori 没有 NaN/Inf，但大范围通过门控，最终达到 1,024 节点预算。代码把零梯度情况下的角度输出为 0；局部全是 0 时轴向一致性很高，当前 ori 门控只有方向一致性、没有结构能量或各向异性置信度，因此无明显方向的平坦区也可能被当作可靠方向场。

另有两项代码层面的几何风险：

1. CNN 的结构张量主轴对应梯度主方向；若 ori 的 Trace_1D 被解释为沿物体边缘延伸，分区切向应与梯度方向相差 π/2。当前 `FeatureSupportBuilder` 使用 `(cos(axis), sin(axis))` 直接连接，没有作这项语义转换。需要先明确 ori 表示的是方向场连贯性还是边缘切向，不能只调整方向连接阈值。
2. `MultiScaleFeatureBank` 对归一化角度直接双线性上采样。轴向角度在正负端点处等价，但数值平均可能得到与它们近乎垂直的方向。应审查改为对 `(cos(2θ), sin(2θ))` 插值后再恢复角度，并结合方向置信度处理低幅值情况。

现有 named orientation → 弧度的输入转换在此路径正常，不是本次 NaN 的来源。

## 5. aps 还存在无结构输入的偏置

全零图片测试中 aps 无 NaN，但输出约为 -0.488，而非零。原因是 `log(ratio + 1e-6)`、方向符号和按最大绝对值归一化共同放大了接近零的数值偏置。因此修复 lambda2 的 NaN 之后，还需要给零能量/近各向同性位置定义无效或零响应。这个 aps 实际是有符号的结构各向异性描述，不是完整目标的几何长宽比。

## 6. 建议处理顺序

1. 先修复 aps 特征值稳定性，以及 curv/aps 的无结构归一化；以零图、常量图、秩一边缘和真实图片检查有限性与背景响应。
2. 给 ori 增加结构能量/各向异性有效性依据，审查轴向插值和切向定义；保留多尺度通道含义一致。
3. 在 CNN 原始输出层显示每尺度 NaN/Inf、有限值范围和置信度，再显示经过门控后的质量；避免仅看清洗后的 Reliability 图。
4. 数值与语义修正后，再检查 curv 的方向估计、种子选取及区域预算；暂不通过降低阈值或增加预算掩盖输入问题。

完整数据集运行结果不能从此次 CPU 单图诊断外推；但 aps 的误差传播链与零输入退化已由代码及复现结果共同确认。
