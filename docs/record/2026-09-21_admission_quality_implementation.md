# 标注对象准入、持续质量与冻结回查实现

日期：2026-09-21。依据 [修正后运行审查](2026-09-21_postcorrection_learning_review.md)。本轮修改正确性与验证接口，继续搁置性能优化；未运行 20 图批量训练、未调参。

## 1. 局部复用歧义不再阻止对象表示

`SupervisedGraphOptimizer.learn_object` 现在区分 unique_reuse、ambiguous_reuse、local_observation。区域候选有歧义、没有同类实体可验证时，保留候选 semantic ID、分数、位置与版本，以本次区域几何建立标注对象，不更新竞争模板。

实体候选打平或存在不可评估的同类竞争实体时，不强行选一个更新，而是保留新的受保护观察及实体候选列表。返回 reuse_decisions / reuse_unresolved，持久化在监督元数据和新区域来源中。未决关联不等于视觉新颖性，novelty_proven 仍为 False；存在未决关联时不标记 visually_confirmed。

无效结构、缺少成员、预算中断仍不能通过“新建”绕过。账本仍只在完整提交后更新，相同观察重放不增加图节点与独立支持。

本轮实现的是待关联观察的保存和保守更新，不包含后续自动合并未决实体的巩固器。待关联记录会占据额外节点，但不会伪装成已确认的新概念。

## 2. 提交前几何校验与一次性修复

三图调试发现：跨对象复用 GmemII 后，拟写入实体可能在原点产生 evidence_conflict。即使分数较高，也可能是不同角色占用同一证据位置，不能提交后再宣称检索失败。

新增 write_validation 阶段，在临时图的实际写入原点验证实体结构。失败时不提交临时图，最多重试一次，使用本次本地观测几何替代区域复用；记录 local_geometry_repair、竞争候选与原始拒绝原因。再次失败则返回 UNRESOLVED。重试沿用原搜索预算，不重置预算计时。

写入原点只参与事务有效性诊断，不传入正常查询。重试前的临时证据、节点和账本均不会进入持久图。几何重试的前段计时单独返回 geometry_retry_prior_stage_seconds，seconds 为完整尝试耗时。

## 3. 来源组选择、持久质量和对应

### 3.1 选择父结构后逐个加入属性

family 排名不再仅由最强子区域决定，收益受父区域质量限制。先保留父结构，再按质量加入属性；预算不足可以舍弃部分属性，不必将整个可用来源组一起丢弃。缺少来源父结构的属性仍被拒绝。

### 3.2 质量持续进入结构验证

实体成员保存 quality_evidence、last_quality、reliability、is_family_root；新区域保存观测质量和复用来源。可靠性由几何与采样质量的观测统计计算；新增/晋升成员也初始化质量。

`entity_view` 按同一 family 内的质量分配证据，父结构的可靠性约束该来源组总强度：

$$
w_{fr}=W_f\frac{q_{fr}}{\sum_{j\in f}q_{fj}},\qquad W_f=E_{f,\mathrm{root}}q_{f,\mathrm{root}}.
$$

$q$ 为成员可靠性，$E$ 为原有证据强度；不带新元数据的历史内部对象采用明确的兼容默认值。非有限、非正或大于 1 的可靠性拒绝作为合法结构。重复加入同源属性不会使该组总权重随成员数线性增加。

前景先验继续单独保存，不将几何质量冒充前景概率。

### 3.3 对应覆盖按独立来源计算

实体匹配的覆盖门限改为父 grad / 独立区域组成的 family 根覆盖，按可靠性加权。属性子区域个数不再直接增加双向覆盖率分母。不同来源组保持一对一对应，完整叶级几何精验及证据唯一性仍必须通过。

本轮没有将多条角色强制映射到同一个输入锚点：这样会直接引入证据重复与错误位置更新。属性碎分不再直接决定对象级覆盖，但任意尺度变化、属性区间的完整多对多配准仍未实现，不能声称已解决所有跨实例变化。

## 4. 分支轮廓不再强行作为单条曲线排序

`RegionSampler._curve_segments` 将区域邻接分解为边不重复的最大非分支路径，交叉点可以共享；闭环和孤立点单独保留。各路径独立选关键点、计算折线误差和生成局部联系，避免通过拼接路径制造跨分支伪连接。

区域语义容器仍是原区域，没有改变 Gmem/Gpos 的节点和边类型。新增 topology_segments / topology_junctions 诊断；预算不足仍标记不完整或截断，不声称路径化必然减少碎片。属性细分继续受 grad 父域约束。

采样行为改变后分区合同升级为 version=4；监督配置新增 learning_contract=supervised-family-quality-v2。旧实验检查点不能直接混用，应建立新池。

## 5. 检索回退触发和候选保留

新增 graph_structural_recall_policy：

- missing：只在无实体命中时回退。
- weak_or_missing（默认）：无命中、最佳实体分数低于既有学习门限、或前两实体接近时补充候选。
- always：诊断时总是补充输入区域候选，用于对比强但错误命中是否遮蔽真正目标。

补充查询与原查询的接受实体按模板合并再做位置抑制，避免回退反而删除已接受假设。未改变精验阈值，也不将近似搜索改称穷举。默认策略无法保证发现“很强且唯一但错误”的初始命中，负例和 always 对照仍必需。
