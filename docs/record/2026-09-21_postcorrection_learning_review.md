当前 19 次失败全部为 `ambiguous region: no verified entity`，没有记录为采样截断或预算耗尽。按类别：car 成功 8/20，dog 6/10，cat 1/4。类别样本偏置会进一步影响后续分类头，不能只看总体提交率。

### 2.2 代码中存在新类别建立的循环依赖

当前流程为：某区域对多个 GmemII 匹配接近 → 暂缓决定 → 寻找同类已有 GmemIII 做联合验证 → 若没有验证实体则拒绝整对象。

当某类尚未建立任何实体时，同类候选自然为空。只要它的颜色或边缘与其它类别已存区域有歧义，第一批该类对象就可能一直无法进入记忆。

日志中的直接例子：第一个对象 003671/dog 成功；第二个对象 007490/object 0/car 立即失败，此时记忆里只有 dog 实体。后一个 car 对象才成功。007530 的 cat 对象在独立空池演示成功，但批量上下文中失败，说明学习结果明显受已有低层区域和顺序影响。

局部相似颜色或边缘在不同对象中重复本来就是合理现象。**“不能确定复用哪个区域模板”和“不能表示当前标注对象”不应是同一状态。**

### 2.3 推荐修正：将局部复用决策与对象准入分离

建议引入显式区域决策类型：

1. `unique_reuse`：存在唯一可靠对应，可以更新该 GmemII。
2. `ambiguous_reuse`：保留候选关联，但不修改任何竞争模板的原型或证据。
3. `local_observation`：为本次可靠区域保存独立观测几何，来源附带标注/观察 ID。
4. `invalid_geometry`：结构或有限性不合法，不能以“新建”绕过错误。

当区域仅为 ambiguous_reuse，但其本地几何可用且监督标注有效时，允许通过 local_observation 建立 annotation_confirmed 实体；可以另设 `reuse_unresolved` 标记。该状态表示复用尚未决定，不表示视觉新颖性已经证明，也不表示已有实体已视觉稳定。

若同类实体存在多个竞争匹配，仍不能随便归并；可先建立受保护的观察记录/待关联实体，在后续独立证据到来时消歧。不要通过放宽全部相似度阈值获得高提交率。

保持事务和账本要求：一次输入最多提交一次；重放不增支持；竞争候选不因本次“疑似匹配”同时获得正证据；关联确认后再合并来源、几何及索引，避免双计数。

**验收**：先写 dog 再写首次出现的 car/cat，与分别空池写入相比，合法对象不应仅因低层模板歧义而无法建立观察表示。允许候选状态不同，但必须保持所有来源可追溯、不误更新既有实体。

## 3. 不完整几何仍在长期记忆中

### 3.1 实测范围

两图构图 completed 分别只有 92/256（35.94%）和 110/256（42.97%），尽管 truncated_regions 都为 0。说明无采样预算截断并不等于结构完整。

检查点的 192 个 GmemII 区域中，有 47 个 is_completed=False（24.48%）：

| 模态 | 完成 | 未完成 |
| --- | ---: | ---: |
| grad | 11 | 15 |
| RGB | 78 | 0 |
| curv | 27 | 3 |
| aps | 17 | 15 |
| ori | 12 | 14 |

这些数字证明未完成状态被持久化；但仅凭检查点的布尔标志，不能把每个未完成区域都断言为同一原因。Notebook 明确显示多个曲线具有 curve_order_unresolved 和 sampling_target_unmet。

### 3.2 为什么现有降权仍不充分

`ObjectRegionSelector` 在候选阶段计算几何/采样质量，但 family 排名使用组内最大候选收益，随后整组加入。一个高质量属性可能带入低质量父轮廓或兄弟属性。

另外，`entity_view` 使用成员证据权重除以 family 成员数；没有读取选择阶段的几何/采样质量。`member_foreground_priors` 保存的是前景项，也没有直接参与这里的结构权重。因此“选择时降权”不等于“检索与学习时持续低置信”。

### 3.3 改进：持续质量状态与父域内拓扑表达

- 持久保存 `ordering_valid`、采样覆盖、几何残差与观测次数，区分临时不完整和结构错误。
- family 必须有有效父结构，但不要用组内最大值替代所有成员质量；先选父结构，再按独立质量加入属性，预算不足时优先保留有效核心。
- 在同一 family 内按成员质量归一化分配权重，使子区域变多不会自动增加该 family 总证据。可采用：

$$
w_{fr}=W_f\frac{q_{fr}}{\sum_{j\in f}q_{fj}+\epsilon}.
$$

这里 $q$ 表示几何/采样可靠性，$W_f$ 表示该来源组的证据强度；零质量组须显式不可评估。不要同时把同一质量重复乘入多个阶段而造成无意的多重惩罚。

- 对 grad 拓扑先检查度数、重复邻接、分支和环。将分支结构表示为最大非分支路径和共享交叉事件，各路径独立排序、采样和计算误差；不要把整个分支图强行当一条曲线。
- curv/ori 在父路径弧长坐标上检查连续性；平滑不跨真实角点或无效间隙。当前 aps 仍是梯度各向异性，应继续与区域长宽比区分。

**验收**：直线、圆环、T/Y 交叉及断裂路径合成例应给出可解释拓扑；新增相关属性不能让同一来源被重复加权；局部缺样不能无理由让整个实体失败或获得高置信。

## 4. 实体匹配需要区分“属性碎分”与“对象差异”

目前 `EntityMatcher` 按角色/区域个数计算双向覆盖率，并执行一对一对应。同一个父轮廓的 curv 或 aps 在另一张图分成不同数量子区域，会改变分母，即使对象主结构相近，也可能过不了覆盖要求。第二张演示有 23 个成员，第一张有 16 个；不能仅凭数量差异认定它们应复用，但现有计数确实受分区碎片数影响。

建议先匹配来源 family 的 grad 几何和独立二维区域，再在对应父域内部对齐属性。实体层覆盖按独立来源质量计算，属性层覆盖按弧长/空间支持量计算：

$$
C=\frac{\sum_f W_f\,\mathbf 1[\text{family } f\text{ 有可靠对应}]}{\sum_f W_f}.
$$

分裂/合并后的属性支持允许多对一或一对多的区间对应，但同一输入像素证据只能计一次。必须保留空间约束，不能因为颜色和方向种类相同就合并两个实体。

另一项待验证问题是平移几何限制。ROI 归一化不能消除不同姿态、部件比例及锚点选择变化。优先测试同对象的已知小平移与尺寸扰动，确定失败来自锚点漂移、区域拆分还是实际变形，再考虑带残差约束的尺度/旋转或可选部件模型。不要要求所有同类实例共用一个 GmemIII。

## 5. 检索成功仍依赖回退，且尚无负例评价

第二张图的稀疏初始查询不能命中，最终依靠输入区域锚点回退。该查询截断事件 98357 个，全局候选截断 184 个；第一图分别为 32271 和 0。这说明候选链路仍是近似的，不能将“未找到”当作“从未见过”。

当前回退仅在整个查询没有任何实体命中时执行。如果错误但可接受的已有实体先命中，正确实体可能仍被遗漏。下一步可以根据低分、类别竞争、覆盖不足或待解释空间触发补充检索，而不是只判断命中数是否为零。诊断时也应能强制运行两路候选取并集，对比漏召回；该对照不能改变正式评价的预算而不说明。

候选覆盖修正增加了真正命中的机会，也可能增加假阳性机会。需要设置同色异形、同形异色、局部部件相似但排布不同等负例，报告误接受率及未决率。

未解决以上问题前，不建议单纯增加候选数量或下调接受阈值作为默认修复。

## 6. 实验记录与下一轮验收

### 6.1 保存和展示一致性

当前 Notebook 单元 1 execution_count 为 None 却有保存输出，批量开关源码与输出状态不同，存在重新编辑/执行后未完整保存的迹象。应在结果汇总单元显式加载所选运行目录的合同、JSONL 和 checkpoint，并打印 run ID；不要默认内存中的 batch_rows 就代表最新磁盘实验。

运行合同目前保存四个 Python 文件哈希，但未覆盖 Notebook 源码及全部运行开关。建议加入 Notebook 代码单元摘要、执行开关、完整 MemoryConfig、样本序列和 checkpoint 图版本。模式对照表中的不适用项显示 N/A，避免 NaN 被误解为模型异常。

### 6.2 建议的小规模验证顺序

1. **新类别准入**：固定 003671/dog → 007490/object 0/car → 007530/cat；观察区域歧义能否以未决复用状态保存，而非整对象弃写。
2. **顺序对照**：相同对象集合用至少两个顺序建立新池；比较成功观察数、候选关联、错误合并和最终原图检索率，允许模板 ID 不同。
3. **所有已提交对象回查**：34 个目标学习结束后，冻结图重新查询所有成功写入对象，区分目标实体命中、同类其它实体命中和完全未命中。不要仅检查账本重放。
4. **独立观察复用**：同对象轻微平移/缩放、局部遮挡；增强样本用于鲁棒性检查，不伪增独立来源证据。记录候选 family、角色覆盖、几何残差和支持变化。
5. **负例与留出分类**：启用 RUN_QUERY，先评价无头类别读出；非零检索覆盖成立后才拟合分类头。保持 memory_build/readout_fit/validation/test 隔离。

本轮留出查询、分类头和检测未执行，没有分类准确率或检测 mAP。已正确接入的三类 test 划分有 1441 张图 / 2048 个目标，这只是可评价样本数，不是已有成绩。
