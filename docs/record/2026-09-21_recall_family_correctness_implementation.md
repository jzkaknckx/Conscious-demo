日期：2026-09-21。依据 [最新运行审查](2026-09-21_notebook_retrieval_and_scaling_review.md)、[长期训练门控记录](2026-09-21_longterm_training_grad_gate.md) 及后续 grad_refined 方案。按用户要求，本轮搁置性能优化，没有实施匹配缓存、GPU 搬迁、多进程或事务复制优化；没有启动批量训练或调参。

## 2. 已实施的检索修改

入口：`graph_memorypool_onceoptimizer.py`。

- 事件预算内优先保留空间分格代表，再补充高响应点，避免同分颜色响应按扫描顺序占满预算。
- 位置桶使用独立角色的响应加权中心，替代首个插入中心；同角色重复投票不重复增加权重。
- 每模板先保留空间分离的姿态。全局预算分轮分配，优先给不同模板各一个候选，避免少数模板占满名额。这仍是近似候选策略，不宣称无漏召回。
- 当稀疏查询没有实体命中时，默认启用 `graph_structural_recall_fallback`：从当前输入重新构建临时区域，提取同模态锚点补充 GmemII 候选，再沿原有超图投票和精验产生 GmemIII。整个过程不使用类别、标注框真值、写入账本或写入原点，且不修改持久图。有效域沿用正常查询输入。
- 回退仅触发一次。它增加构图及候选精验工作，不是性能优化；可以通过配置关闭做对照。候选来自有限区域，因此仍保持 `search_complete=False`，未命中不构成新颖性证明。若已有其它实体命中，它不会自动继续搜索所有可能实体；多目标召回仍需独立评价。
- 增加事件截断、姿态抑制/截断、每层候选数、接受区域数及可选 `trace=True` 诊断。`StructureMatch` 明确记录分数、可评估率、覆盖、几何误差与证据冲突拒绝原因。

输入区域回退复用了有限预算的现有构图器，属于增加召回来源。没有改变 Gmem/Gpos 节点与边的结构定义。

## 3. 成员选择与监督更新

入口：`supervised_graph_learning.py`、`supervised_data.py`。

- 统一 `region_family()`：优先读取 `support_parent_region_id`，兼容旧 `parent_region_id`。选择和实体对应使用同一来源定义；属性不再作为与父轮廓无关的独立 family。
- 来源父区域不可写/未入组时，明确拒绝孤立属性。更新后也检查需要绑定的模态是否仍有 grad 来源；保留旧模式 curv 不强制绑定的语义。
- 选择质量拆为前景、几何、采样三项。曲线排序未解决与采样未完成分别软降权，而非将框内候选一律记作质量 1，也不一刀切丢弃所有不完整区域。
- 大小收益先在同模态归一化，减少长度和面积直接竞争的偏置；通过 `modality_diversity_bonus` 给可靠的新模态加软奖励，不强制凑齐五种模态。
- `incomplete_geometry_weight` 与 `modality_diversity_bonus` 写入配置并参与检查点合同；诊断输出 `quality_components`。成员前景先验仍保存真正的前景项，避免将几何质量冒充前景概率。
- 单区域歧义不立即否决：保留通过精验的候选，先执行实体匹配。只有唯一已验证实体对应到同一语义成员、且位置相容时才消歧。没有已验证实体、对应不唯一或证据不足仍返回 UNRESOLVED，不强行创建新实体。此路径保留原有搜索预算与提交前事务边界。

本次降权使未完成几何不再与完整区域同等竞争，但没有把分支轮廓改造成最大非分支路径，也没有证明碎片问题已完全解决。aps 仍是原 CNN 各向异性特征；真正区域形状函数沿用前次诊断接口，未偷换原型含义。
