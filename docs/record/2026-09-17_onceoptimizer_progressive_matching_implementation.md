# 区域匹配：保守上界早退、局部像素响应与预算接口

依据 [算法调整建议](2026-09-17_onceoptimizer_algorithm_revision_proposal.md)，本次实现第一轮结果保持型区域匹配调整。Gmem/Gpos 的层级、节点／边语义、学习阈值、歧义规则及原有稀疏后密集补查分支保持不变。

## 实现范围

修改 `src/nns/memorygraphs/graph_memorypool_onceoptimizer.py`：

- **可评估性前移**：先按模态批量采样槽位的有效域，得到候选位置最终的可评估权重 E。低于下限的候选不再获取描述子响应。
- **分批槽位与保守上界**：权重大者优先，同权优先根槽位；默认每批 8 个槽位。未核验槽位假设得分为 1，根据已核验的加权对数分数与确定的 E 计算总分上界，并计算最高可能覆盖率。即使剩余槽位完全命中也不能达标的候选立即停止；边界保留 1e-12 容差，由原验证器最终决定。
- **参考验证不变**：幸存候选继续用原槽位顺序、评分、赋值、角色冲突、几何核验和范围检查。上界只用于拒绝，不直接决定接受。不因为找到一个匹配就跳过其它竞争模板。
- **局部像素响应**：稀疏采样请求只在所需像素的保守包围矩形计算原相似度。门控沿用全图结果，局部掩码单独应用；将局部分数填到原图坐标的临时响应画布，再调用原 `grid_sample`。没有先插值描述子，没有改变原图坐标归一化。矩形含插值邻居和舍入保护边界，面积过大或完整响应已经缓存时复用原全图路径。
- **候选调度**：优先验证原全局查询已经支持的模板，但继续遍历全部必要同模态模板；最终排序与歧义判断不变。没有引入未经覆盖保证的硬 top-k 或 ANN 截断。
- **诊断**：新增可评估性拒绝数、上界拒绝数、实际采样槽位×中心数、局部矩形次数、局部像素数和相对于全图请求避免计算的像素数。原 `dense_slot_centers` 保留为未剪枝的名义工作量。

本轮未把观察构图移到全局查询之前，也未增加新的描述子召回索引。现有全局查询已较快；优先在占时最高的区域搜索内消除不必要计算，避免一次改变候选来源和评分路径。

## 配置与预算接口

新增默认配置：

```python
graph_progressive_matching = True
graph_slot_batch = 8
graph_local_response_fraction = 0.25
graph_search_budget_seconds = None
graph_search_budget_templates = None
```

`graph_progressive_matching=False` 可使用前一版完整采样后筛选路径作为对照。局部矩形比例是执行策略，不是匹配阈值；设为 0 可让局部请求始终走原全图响应路径。共享缓存预算保持原 256 MiB，没有在本次调大显存配置。

`SearchBudget` 可通过 `learn_view(..., search_budget=...)`、`handle_new_view`、`Controller.run_step` 及优化器 `learn` 传入，也可由配置生成：

```python
from nns.memorygraphs.graph_memorypool_onceoptimizer import SearchBudget

# 默认：不限制区域搜索，完成原有必要候选检查。
result = learner.learn_view(features, valid_mask=mask, episode_id=episode)

# 保留选项；不是本次默认启用的设置。
result = learner.learn_view(
    features, valid_mask=mask, episode_id=episode,
    search_budget=SearchBudget(max_seconds=30, max_template_pairs=1000),
)
if result.diagnostics.get('learning_status') == 'UNRESOLVED':
    # 本次观察没有写入长期图。调用者应保留输入，稍后增加预算或取消预算重试。
    pass
```

预算从区域搜索阶段开始计时，按模板、中心块、槽位批协作检查，不预占正在运行的 CUDA 算子，也不限制 CNN、构图、前置查询或提交。因此不能当作整步严格耗时上限。

预算耗尽时返回 `learning_status=UNRESOLVED`、`observation_committed=False`、`retry_required=True`、原因和区域编号，**整次观察不提交**：不新建区域，不强化证据，也不把未检查当负证据。正常完成返回 `COMMITTED`。同一个预算对象在每次学习调用时重新开始计数。没有后台队列或自动断点续检，未来可在调用者层面接入；目前重试整张输入，并保持 episode 不变。

Notebook 第 8 节补充新计数说明及未提交结果检查；若未来启用预算而中断，本节写入诊断并停止，不继续把该图片计为成功。默认两个预算均为 None，因此此次不限制单步运行时间。修改前 Notebook 已备份在本次结果目录。

## 验证结果

[回归测试](../../src/tests/test_onceoptimizer_performance.py) 共 8 项，分别在 CPU 和 GPU 上通过，覆盖：共享掩码隔离、缓存淘汰、缺失／非有限信息、阈值前筛、局部响应的分数插值、孔洞／缺失槽位的递进匹配、早退减少槽位访问、预算中断不提交及随后重试。

源码与 Notebook 静态编译通过，`git diff --check` 通过。

RTX 5060 Ti 上使用同一冻结记忆、同一真实图片的 12 个小区域（37–93 像素）对照上一版代码：

| 模板对数 | 672 | 672 |
| 密集回退次数 | 669 | 669 |

| 名义槽位×中心 | 605,571 | 605,571 |
| 完整响应图计算 | 665 | 0 |

本版实际评分槽位×中心为 **19,211**；33,796 个中心在可评估性阶段被排除，4,299 个由后续上界排除。计算了 903 个局部矩形、466,190 个响应像素；0 张完整响应并不意味着没有进行相似度计算。

最终匹配摘要与歧义判断一致，局部匹配单次约 **3.73 倍加速**。全局查询摘要也一致，耗时约 1.88／1.85 秒，本次没有宣称这部分进一步加速。

基准脚本、上一版实现与原始结果见 [results/algorithm_20260917](../../results/algorithm_20260917/)。这是有界样本、旧先新后的单次对照，不代表完整多图片训练的加速比或所有输入的等价性证明。未重新执行 593 张图片训练。

## 剩余限制

区域—模板对和名义候选中心数量仍可能随记忆增长；本次只减少其中实际需要的槽位评分与全图响应。高覆盖、重复纹理、大区域等难例可能难以早退，局部矩形也可能退化为全图。

局部响应为了保持插值坐标语义，仍分配一个完整大小的临时画布；当前没有承诺完全消除 O(HW) 初始化成本。评分上界以 NumPy float64 聚合，角色／几何验证仍在 CPU，尚未实现完整 GPU 前筛链路。后续可在保持数值与边界语义的前提下进一步融合。
